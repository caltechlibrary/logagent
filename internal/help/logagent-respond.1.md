# NAME

{app_name}-respond - generate, and with confirmation apply, web server configuration

# SYNOPSIS

{app_name} respond [OPTIONS]

# DESCRIPTION

**This command is planned and is not implemented yet.** This page is a
placeholder and will be completed as the design and implementation are settled.

{app_name} respond is intended to generate web server configuration that limits
automated traffic. It would be a dry run by default, and apply a change only on
confirmation and only after the server's own configuration test passes.
