# NAME

logagent-watch - follow a log and raise alerts on bursts

# SYNOPSIS

logagent watch [OPTIONS]

# DESCRIPTION

**This command is planned and is not implemented yet.** This page is a
placeholder and will be completed as the design and implementation are settled.

logagent watch is intended to follow an access log, learn a baseline, and raise
an alert when traffic bursts or a group of requests with a shared fingerprint
grows in cost.
