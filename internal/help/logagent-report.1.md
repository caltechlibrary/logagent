# NAME

{app_name}-report - summarize automated traffic and its cost

# SYNOPSIS

{app_name} report [OPTIONS]

# DESCRIPTION

**This command is planned and is not implemented yet.** This page is a
placeholder and will be completed as the design and implementation are settled.

{app_name} report is intended to summarize automated traffic from an access
log: requests and the load they put on the application, grouped by family of
client, ranked by cost and not by request count.
